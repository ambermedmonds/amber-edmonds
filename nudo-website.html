Nudo House Website

For my Visual Principles for the Screen class at WashU, I worked on an experimental front-end development project focused on rapid iteration and constraint-based design. Using the menu of a local St. Louis restaurant called Nudo House, I built 20 distinct design variations progressing from plain text markdown and HTML to complex CSS grid layouts, multimedia integrations, and interactive elements. The final result combines these explorations into a polished, fully responsive website alongside a digital archive documenting the entire process through all 20 design variations.
