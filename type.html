Web Design

Evolution of Type Website

This project focused on translating a book into a website.

When

Oct-Nov 2024

Role

Web Designer

Tools

Figma

Objective

This project focused on adapting the book The Evolution of Type: A Graphic Guide to 100 Landmark Typefaces by Tony Seddon into a web experience that allows users to explore different typefaces in an engaging way.

Process
  • Content Strategy: Formulated color palettes, moodboards, and a content map ↗ milestone 1
  • Design Directions: Sketched 2 visual directions to test colors, layout, navigation, etc. ↗ milestone 2
  • Wireframing + Iteration: Chose a direction and created desktop and mobile wireframes↗ milestone 3
  • Final Design: Developed a high-fidelity prototype in Figma, including mobile + desktop ↗ view prototype
  • Physical Item Mockup: Extended the design system into a physical pencil pouch mockup ↗ view mockup
Outcome

Created a cohesive digital prototype, design system, and physical brand extension that translates the original book's ethos into an interactive web experience.


Note: The prototype features a curated selection of typefaces across chapters rather than all 100 entries due to project time constraints.
