Web + Interactive Design

Smiski Website

This project focused on bringing a playful digital concept to life through AI-assisted development, real-time API integrations, and an interactive web layout.

When

May 2026

Role

Web Designer + Developer

Tools

HTML/CSS/JS, Codex AI

Objective

Design and build an original, dollhouse-style web application that gamifies product discovery through responsive room navigation and dynamic UI features.

Process
  • Defined an interactive concept and user flow
  • Translated ideas into VS Code using Codex AI to rapidly prototype interactive hotspots API integrations
  • Fine-tuned UI elements, color palettes, modal overlays, and room transitions for a cohesive site experience
Key Features
  • Fetches real-time location and time data to dynamically toggle between Day and Night themes
  • Navigates seamlessly between rooms with arrow controls and quick jumps back to the main house layout
  • Opens custom character modals when clicking interactive Smiskis in each room
  • Saves and pins favorite Smiskis across different sessions in a dedicated sidebar
Outcome

Delivered a web app that combines creative vision, AI-assisted development, and real-time API integrations into a memorable product experience.
